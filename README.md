# Hệ thống Quản lý Đồ án và Phân công Giảng viên Hướng dẫn

## Giới thiệu

Đây là dự án môn học được xây dựng bằng **Laravel**, nhằm hỗ trợ quản lý quy trình thực hiện đồ án của sinh viên, từ đăng ký đề tài, phân công giảng viên hướng dẫn đến theo dõi các mốc nộp.
